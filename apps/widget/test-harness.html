Card Pricer widget — test harness (S9 + S23)

Each section drops a script tag exactly the way a customer shop would. Sections 1+2 must produce visually identical buttons (V1-attribute parity contract per docs/V2_ARCHITECTURE.md Q4). Sections 3-6 exercise V2-NEW attributes. Section 7 (S23) loads V1 and V2 side-by-side in sandboxed iframes for a tight visual diff. The Comparison panel logs every cp:submitted payload that bubbles to window.cardPricerWidgetOnSubmit.

Open in a real browser via file:///…/apps/widget/test-harness.html. For the automated counterpart see tests/regression/widget-runtime.spec.js (jsdom DOM-diff parity, run with npm test).

1. V1 only — rollback target / control

Loads apps/widget/widget-v1.js. This is the verbatim copy of the live public/widget.js (V1). Use as the visual baseline for parity comparisons.

2. V2 with V1-only attributes — parity check

Loads apps/widget/widget.js (V2) but passes ZERO V2 attributes. The button + modal MUST be visually indistinguishable from section 1. This is the RG-41 contract.

3. V1 + V2 mixed — additive attributes

V1 attrs plus data-button-shape="pill" and data-event-callback="onPillSubmit". The button rounds to a pill; on submit, both cardPricerWidgetOnSubmit AND onPillSubmit fire.

4. Light theme — RG-42

Modal chrome flips to the light palette (bg #fafaf9, text #0c0a09). Button background is still data-color with white text (button is brand-coloured, not theme-coloured).

5. Compact modal size

Modal sizes drop from min(820px, 100%) × min(900px, 90vh) (V1 default) to min(560px, 100%) × min(720px, 85vh).

6. Lazy-load — defers iframe until first click

V1 already lazy-builds the modal on first click; this attribute exists for symmetry / future tightening. Today it's a no-op vs section 2 in behaviour but is documented for completeness.

7. Side-by-side V1 ↔ V2 — visual parity (S23)

Two child documents, each loading one widget verbatim with the same data-shop="brewed" + V1 defaults. The buttons should be pixel-identical; clicking each opens the modal so you can eyeball the backdrop, inner box, and close button.
